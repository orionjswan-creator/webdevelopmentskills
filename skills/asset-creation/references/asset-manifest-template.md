# Asset manifest template

`assets/manifest.md` is the contract between the asset-creation skill and the site-builder
skill. IDs and paths never change once code references them; everything else can be revised.

````md
# Asset manifest — <brand>

## Art direction (inherited by every image prompt)
- Medium: 35mm editorial photography, shallow depth of field
- Palette: deep forest green, warm cream, charcoal (accents: burnt orange)
- Lighting: soft directional daylight, deep soft shadows
- Mood: assured, quiet, tactile
- Composition: generous negative space, subjects off-center
- Always exclude: text, watermarks, logos, faces in focus (unless entry says otherwise)

## Inventory

| # | id | path | dimensions | format | role | status |
|---|----|------|-----------|--------|------|--------|
| 1 | logo-wordmark | assets/svg/wordmark.svg | 320×64 | svg | header, footer | final |
| 2 | hero-main | assets/img/hero.avif | 2880×1620 | avif | homepage hero | placeholder |
| 3 | work-01 | assets/img/work-01.avif | 1600×2000 | avif | work grid, card 1 | todo-describe |
| 4 | team-founder | assets/img/team-founder.avif | 1200×1500 | avif | about page | awaiting-user |
| 5 | og-default | public/og.png | 1200×630 | png | share card | final (generated by assets/scripts/og.mjs) |

## Prompt specs

### hero-main
- **Tool**: Midjourney v7 (fallback: FLUX Pro)
- **Prompt**: 35mm editorial photograph of a sunlit ceramic studio workbench with unfinished
  vessels, generous negative space upper right for headline overlay, deep forest green and warm
  cream palette, soft directional daylight with deep soft shadows, assured quiet tactile mood
- **Exclude**: text, watermarks, logos, people
- **Params**: `--ar 16:9 --style raw --no text, watermark`
- **Alt**: Unfinished ceramic vessels on a sunlit studio workbench
- **Post**: crop to 16:9 → `node assets/scripts/compress.mjs in.png assets/img/hero.avif 2880`

### work-01
- **Prompt**: TODO(describe: what is this project/product? give me 1–2 sentences about what the
  image should show)
- **Alt**: TODO
- (Everything else inherits art direction; aspect 4:5; `--ar 4:5 --style raw`)

### team-founder
- **Status**: awaiting-user — please supply a real photo, ≥ 1200×1500, portrait orientation.
  We will match-grade it to the palette in post (compress script applies a subtle warm curve).

## Generation guide
1. Generate `hero-main` first and iterate until it matches the art direction — it becomes the
   style anchor (`--sref` its URL for all subsequent Midjourney generations).
2. Batch-generate remaining `placeholder`/`todo-describe` entries (after filling TODOs), only
   changing the subject clause.
3. Run the compress script on each; save at the exact manifest path. Placeholders are replaced
   automatically — no code changes.
4. Licensing: confirm commercial rights on your image-tool plan before shipping.

## Status summary
- Final: 2 · Placeholder specs ready: 1 · Needs description: 1 · Awaiting user: 1
````

## Rules

- **Dimensions use `×`** (the placeholder script parses `NNN×NNN`).
- `status` values: `final` | `placeholder` (spec ready, image not yet generated) |
  `todo-describe` (needs user input in a `TODO(describe:)` slot) | `awaiting-user` (real file
  required).
- Every entry has `alt` text before it can become `final`.
- One prompt-spec heading per non-final image entry, `###` + the id, so tools can parse it.
- The site-builder greps this file: any image path in code missing from the inventory is a
  build-gate failure.
